\section{Fonctionnalités terminées et opérationnelles}

\subsection{Architecture et socle technique}

\begin{itemize}
  \item[\cmark] Framework \textbf{Laravel} (backend monolithique, PHP 8.x)
  \item[\cmark] Authentification classique + \textbf{Socialite} (Google, Facebook)
  \item[\cmark] Système de thème \textbf{Dark / Light} avec persistance de session
  \item[\cmark] Multilinguisme \textbf{FR / EN} complet (fichiers \texttt{lang/fr} et \texttt{lang/en})
  \item[\cmark] Header responsive avec menu \textbf{hamburger mobile} (masquage auto $\leq$ 1024 px)
  \item[\cmark] Seeds automatiques : 16 catégories, 7 plans d'abonnement, admin initial, paramètres système
\end{itemize}

\subsection{Espace Lecteur}

\begin{itemize}
  \item[\cmark] Catalogue, exploration et moteur de recherche avancé (filtres catégorie, type, langue, tri)
  \item[\cmark] Bibliothèque personnelle (ajout, suppression, rétention 50\,\% post-expiration)
  \item[\cmark] Lecteur \textbf{PDF.js} intégré avec protection anti-capture d'écran :\\
        filigrane (watermark), détection de perte de focus, blocage des touches d'impression
  \item[\cmark] Progression de lecture sauvegardée automatiquement (toutes les 60 secondes)
  \item[\cmark] Signets de lecture : ajout du signet courant + \emph{click-to-jump} vers la page sauvegardée
  \item[\cmark] Système d'avis : note 1-5 étoiles + texte, détection doublon, \texttt{is\_verified\_purchase},\\
        mise à jour automatique de la note moyenne du livre
\end{itemize}

\subsection{Espace Auteur}

\begin{itemize}
  \item[\cmark] Publication de livres — CRUD complet : upload PDF (max 100 Mo), couverture JPG/PNG, ISBN/DOI
  \item[\cmark] Statut de soumission : brouillon $\to$ en attente $\to$ approuvé / rejeté
  \item[\cmark] Statistiques auteur : vues, lectures et revenus par livre
  \item[\cmark] Chroniques / articles — CRUD complet
  \item[\cmark] \textbf{Wallet} : solde en temps réel, montant en attente, 10 dernières transactions
  \item[\cmark] Demande de retrait MTN MoMo / Orange Money (seuil minimum + seuil de lectures requis)
\end{itemize}

\subsection{Espace Administrateur}

\begin{itemize}
  \item[\cmark] Tableau de bord : 7 KPIs clés (utilisateurs, livres, abonnements, revenus…)
  \item[\cmark] Gestion des utilisateurs : CRUD, activation/désactivation, gestion des rôles
  \item[\cmark] Validation des publications : aperçu, approbation (email newsletter auto), rejet motivé
  \item[\cmark] Signalements : \texttt{dismiss}, \texttt{warn\_author}, \texttt{remove\_book}
  \item[\cmark] Plans d'abonnement — CRUD complet
  \item[\cmark] Newsletter : envoi de campagnes email à tous les abonnés actifs
  \item[\cmark] Statistiques : top 10 livres et auteurs, évolution sur 12 mois
  \item[\cmark] Rapport financier : revenus, commissions, retraits par mois
  \item[\cmark] Livre de bienvenue (désignation d'un livre gratuit pour les nouveaux inscrits)
  \item[\cmark] Paramètres système : panneau de configuration global
\end{itemize}

\subsection{Pages d'information et de support}

MAIL_PASSWORD=your_password
MAIL_ENCRYPTION=tls
MAIL_FROM_ADDRESS=ocali597198@gmail.com
MAIL_FROM_NAME="OCaLi"
\end{verbatim}
\end{infobox}

\subsection{Commandes à exécuter sur le serveur}

\begin{infobox}
\begin{verbatim}
# 1. Migrations + seeds (une seule fois sur un serveur vierge)
php artisan migrate --seed --force

# 2. Optimisations production
php artisan config:cache
php artisan route:cache
php artisan view:cache

# 3. Permissions de stockage
chmod -R 775 storage bootstrap/cache
chown -R www-data:www-data storage bootstrap/cache
\end{verbatim}
\end{infobox}

\begin{alertbox}[{\warn\ Important}]
Ne pas exécuter \texttt{db:seed} plusieurs fois sans \texttt{migrate:fresh} pour éviter les entrées dupliquées.
Les seeds initialisent : 16 catégories, 7 plans d'abonnement, le premier compte admin et les paramètres système.
\end{alertbox}
